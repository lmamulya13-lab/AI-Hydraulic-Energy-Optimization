
# AI-Driven Energy Optimization of Hydraulic Power Units

## Project Overview
An interactive 3D simulation of a hydraulic power unit using Python and VPython. The project demonstrates hydraulic operations, demand prediction and energy optimization.

## Features
- Interactive 3D hydraulic system
- Oil reservoir, electric motor and hydraulic pump
- Directional control valve
- Hydraulic cylinder
- Animated oil flow
- Live pressure and flow monitoring
- Oil temperature monitoring
- Adaptive motor-speed control
- AI-inspired demand prediction
- Electrical power monitoring
- Energy consumption calculation
- Normal vs optimized energy comparison
- Energy-saving estimation
- Live graphs
- CSV data export

## Technologies Used
- Python
- VPython
- Mathematical Modelling

## Installation

Install the required library:

pip install vpython

## How to Run

python hydraulic_ai_simulation_upgraded.py

## Project Type
Engineering / Artificial Intelligence Project

## Disclaimer
This is an educational simulation and is not designed to control real hydraulic machinery.
